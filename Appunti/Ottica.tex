\section*{Introduzione: Analisi Dati con Python (Facoltativo)}

In questo capitolo vengono introdotti gli strumenti software per l'analisi statistica dei dati sperimentali. Il framework di riferimento è \textbf{Python}, in particolare utilizzando la libreria \texttt{iminuit} per l'ottimizzazione dei parametri tramite il metodo dei minimi quadrati ($\chi^2$).

\subsection*{Fit di un Istogramma con una Gaussiana}

Il primo esempio mostra come generare un set di dati distribuiti secondo una normale (Gaussiana), riempirne un istogramma e successivamente effettuare un fit per estrarre i parametri della distribuzione. 

La funzione Gaussiana utilizzata per il fit è definita come:
\begin{equation}
    f(x; C, \mu, \sigma) = C \exp\left(-\frac{1}{2}\left(\frac{x - \mu}{\sigma}\right)^2\right)
\end{equation}

Di seguito il codice completo:

\begin{lstlisting}[caption={Generazione e fit di un istogramma Gaussiano}]
import numpy as np
import matplotlib.pyplot as plt
from iminuit import Minuit

# 1. Generazione dati fittizi (Gaussiana con mu=-5.5, sigma=0.5)
with open('datpy.txt','w') as file:
  for i in range(1000):
    g = np.random.normal(-5.5, 0.5)
    file.write('%s\n' % (g))

# 2. Lettura dati e creazione istogramma
dati = np.loadtxt("datpy.txt")
x = dati

plt.figure()
counts, bins, _ = plt.hist(x, range=(-10,0), bins=50, alpha=0.6)

# 3. Definizione del modello e del Chi Quadrato
def gauss(x, par0, par1, par2):
    return par0 * np.exp(-0.5 * np.power((x - par1) / par2, 2.0))

def chi2(par0, par1, par2):
    mask = counts > 0 # Evita la divisione per zero nei bin vuoti
    # x dei bin valutato nel punto medio
    x_mid = (bins[:-1] + bins[1:])[mask] / 2
    y_teo = gauss(x_mid, par0, par1, par2)
    err_y = np.sqrt(counts[mask])
    return np.sum(((counts[mask] - y_teo) / err_y)**2)

# 4. Minimizzazione con Minuit
m = Minuit(chi2, par0=1.0, par1=0.0, par2=1.0)
m.migrad() # Algoritmo di minimizzazione
m.hesse()  # Calcolo della matrice di covarianza
m.minos()  # Stima asimmetrica degli errori (opzionale)

# Estrazione dei parametri
Constant_fit = m.values["par0"]
Mean_fit = m.values["par1"]
Sigma_fit = m.values["par2"]

# [...] (Codice per il plot omesso per brevità)
plt.show()
\end{lstlisting}

\subsection*{Fit non lineare, errori su ambo gli assi e Analisi dei Residui}
Questo secondo script simula un decadimento esponenziale $y = A e^{-x/B}$ ed esegue un'analisi completa in tre fasi:
\begin{enumerate}
    \item \textbf{Fit del modello:} Esegue la minimizzazione considerando la varianza efficace.
    \item \textbf{Distribuzione dei residui:} Verifica che i residui normalizzati, definiti come $r_i = \frac{y_i - f(x_i)}{\sigma_{eff, i}}$, seguano una distribuzione Normale standard $N(0,1)$.
    \item \textbf{Andamento dei residui:} Esegue un fit lineare ($y = P_0 + P_1 x$) sul grafico dei residui in funzione di $x$. Se il modello iniziale è corretto, non ci dovrebbero essere trend sistematici (ci si aspetta $P_0 \simeq 0, P_1 \simeq 0$).
\end{enumerate}

\begin{lstlisting}[caption={Fit esponenziale con varianza efficace e studio dei residui}]
import numpy as np
import matplotlib.pyplot as plt
from iminuit import Minuit

# --- 1. LETTURA DATI ---
dati = np.loadtxt("datpy.txt")
x = dati[:,0]
y = dati[:,1]
ex = dati[:,2]
ey = dati[:,3]

# --- 2. FIT ESPONENZIALE (METODO VARIANZA EFFICACE) ---
def fitfunc(x, par0, par1):
    return par0 * np.exp(-x / par1)

def fitfuncprime(x, par0, par1):
    dx = 1e-6
    # Derivata numerica
    return (fitfunc(x+dx/2, par0, par1) - fitfunc(x-dx/2, par0, par1))/dx

def chi2_eff(par0, par1):
    # Propagazione dell'errore di x su y tramite derivata
    sigma_eff = np.sqrt(ey**2 + (ex * fitfuncprime(x, par0, par1))**2)
    return np.sum(((y - fitfunc(x, par0, par1)) / sigma_eff)**2)

m1 = Minuit(chi2_eff, par0=1.0, par1=1.0)
m1.migrad()
A_fit, B_fit = m1.values["par0"], m1.values["par1"]

# --- 3. ANALISI DISTRIBUZIONE DEI RESIDUI ---
y_res = y - fitfunc(x, A_fit, B_fit)
ey_eff = np.sqrt(ey**2 + (ex * fitfuncprime(x, A_fit, B_fit))**2)

counts, bins, _ = plt.hist(y_res / ey_eff, range=(-10,10), bins=20)

def gauss(x, par0, par1, par2):
    return par0 * np.exp(-0.5 * np.power((x - par1) / par2, 2.0))

def chi2_res(par0, par1, par2):
    mask = counts>0
    x_mid = (bins[:-1] + bins[1:])[mask]/2
    return np.sum(((counts[mask] - gauss(x_mid, par0, par1, par2)) / np.sqrt(counts[mask]))**2)

m2 = Minuit(chi2_res, par0=1.0, par1=0.0, par2=1.0)
m2.migrad()

# --- 4. RICERCA TREND SISTEMATICI SUI RESIDUI ---
def retta(x, par0, par1):
    return par0 + par1 * x

def chi2_trend(par0, par1):
    return np.sum(((y_res - retta(x, par0, par1)) / ey_eff)**2)

m3 = Minuit(chi2_trend, par0=0.0, par1=0.0)
m3.migrad()
\end{lstlisting}

\subsection*{Il Framework ROOT}

ROOT può essere utilizzato in due modi, entrambi illustrati di seguito:
\begin{itemize}
    \item Tramite \textbf{Macro C++} (file \texttt{.C}), che vengono compilate o interpretate nativamente.
    \item Tramite \textbf{PyROOT} (file \texttt{.py}), un \textit{wrapper} che permette di usare le classi C++ di ROOT all'interno di uno script Python.
\end{itemize}

\begin{definizione}[title={Oggetti fondamentali in ROOT}]
Nella sintassi di ROOT, ogni oggetto inizia tipicamente per \texttt{T}:
\begin{itemize}
    \item \texttt{TCanvas}: Dove vengono disegnati i grafici.
    \item \texttt{TH1F}: Istogramma monodimensionale (1D) con frequenze in formato \textit{float}.
    \item \texttt{TGraphErrors}: Grafico a dispersione per coppie di dati $(x,y)$ con rispettivi errori $(\sigma_x, \sigma_y)$.
    \item \texttt{TF1}: Funzione matematica 1D, utilizzata per eseguire i fit.
\end{itemize}
\end{definizione}

\subsection*{Fit Base: Istogramma e Gaussiana (Macro C++)}

Questo esempio mostra come leggere una colonna di dati, riempire un istogramma \texttt{TH1F} e fittarlo con una funzione di Gauss. In ROOT, funzioni comuni come la Gaussiana sono già predefinite nella libreria matematica \texttt{TMath}. 
Di seguito è riportato il codice in C++ (\texttt{fit.C}):

\begin{lstlisting}[language=C++, caption={Macro C++ per fit Gaussiano con ROOT}]
#include "TMath.h"
#include "TF1.h"
#include "TH1F.h"
#include "TCanvas.h"
#include <fstream>

// Definizione della funzione di fit
double fitfunc(double* x, double* p) {
   double norm = p[0];
   double mean = p[1];
   double sigma = p[2];
   return norm * TMath::Gaus(x[0], mean, sigma);
}

void fit() {
   const int mpt = 9999;
   float x1[mpt];
   int npt = 0;

   // 1. Lettura dati da file
   std::ifstream in("dat.txt");
   while (in.good()) {
      in >> x1[npt];
      if (!in.good()) break;
      npt++;
   }
   in.close();

   // 2. Creazione Canvas e Istogramma
   TCanvas* c1 = new TCanvas("c1", "c1", 0, 0, 500, 500);
   TH1F* h1 = new TH1F("h1", "h1", 100, -10.0, 25.0);

   for (int i = 0; i < npt; i++) {
     h1->Fill(x1[i]);
   }

   // 3. Definizione TF1 e Fit
   TF1* f1 = new TF1("f1", fitfunc, -100.00, 100.0, 3);
   f1->SetParameters(7.100, -5.100, 0.100);
   f1->SetParNames("A", "B", "C");

   gStyle->SetOptStat(kFALSE);
   gStyle->SetOptFit(kTRUE); // Mostra il box con i risultati del fit

   c1->cd();
   h1->Fit("f1");
   f1->SetLineColor(kRed);
   f1->Draw("same"); // Disegna la funzione sopra l'istogramma
}
\end{lstlisting}

\subsection*{Fit Avanzato: TGraphErrors e Residui (PyROOT)}

Nel caso di misure $(x,y)$ con incertezze su entrambi gli assi, si utilizza la classe \texttt{TGraphErrors}. Questo script mostra l'implementazione in \textbf{PyROOT}. 

Lo script esegue il fit dei dati, calcola gli errori efficaci, costruisce l'istogramma dei residui e verifica l'assenza di trend sistematici tramite un fit lineare (polinomio di grado 1: \texttt{pol1}):

\begin{lstlisting}[language=Python, caption={Fit con Varianza Efficace e Residui tramite PyROOT}]
import ROOT
import array

# 1. Definizione della funzione (Esponenziale)
def fitfunc(x, p):
  return p[0] * ROOT.TMath.Exp(-x[0] / p[1])

# Inizializzazione array tipizzati (necessari per interfacciarsi col C++ di ROOT)
x1, x2, x3, x4 = array.array('f'), array.array('f'), array.array('f'), array.array('f')

# [ ... Lettura file datpy.txt omessa per brevità ... ]

npt = len(x1)

# 2. Creazione Graph e Fit Principale
c1 = ROOT.TCanvas('c1', 'Fit Esponenziale', 0, 0, 500, 500)
gr = ROOT.TGraphErrors(npt, x1, x2, x3, x4)

f1 = ROOT.TF1('f1', fitfunc, 0.00, 10.00, 2)
f1.SetParameters(0.0, 1.0)
f1.SetParNames('A', 'B')

ROOT.gStyle.SetOptFit(ROOT.kTRUE)

c1.cd()
gr.Fit(f1) # ROOT si occupa della minimizzazione
gr.SetLineColor(ROOT.kBlue)
gr.Draw('AP') # A=Assi, P=Punti
f1.SetLineColor(ROOT.kRed)
f1.Draw('same')

# 3. Analisi dei Residui Normalizzati (con errore efficace calcolato da ROOT)
x4b = array.array('f') # conterra' gli errori efficaci calcolati

for i in range(npt):
  # Varianza efficace usando f1.Derivative()
  var_eff = x4[i]**2 + (x3[i]*f1.Derivative(x1[i]))**2
  x4b.append(ROOT.TMath.Sqrt(var_eff))

h1 = ROOT.TH1F('h1', 'Distribuzione Residui', 20, -10.0, 10.0)

for i in range(npt):
  resid = (x2[i] - f1.Eval(x1[i])) / x4b[i]
  h1.Fill(resid)

# Fit dei residui con Gaussiana
c2 = ROOT.TCanvas('c2', 'Residui', 600, 0, 500, 500)
fgaus = ROOT.TF1('fgaus', 'gaus', -2.0, 2.0)
fgaus.SetParameters(3.0, 0.0, 1.0)
c2.cd()
h1.Fit(fgaus)

# 4. Trend dei residui vs x
y2 = array.array('f')
for i in range(npt):
  y2.append(x2[i] - f1.Eval(x1[i]))

c3 = ROOT.TCanvas('c3', 'Trend Residui', 300, 300, 500, 500)
gr1 = ROOT.TGraphErrors(npt, x1, y2, 0, x4b) # X ha errore 0 qui per il plot
g1 = ROOT.TF1('g1', 'pol1', 0.00, 10.00) # Fit lineare

c3.cd()
gr1.Fit(g1)
gr1.Draw('AP')
g1.Draw('same')

# Salvataggio su file
c1.SaveAs('c1.png')
c2.SaveAs('c2.png')
c3.SaveAs('c3.png')
\end{lstlisting}







\section*{Richiamo sulle equazioni di Maxwell}
In \textbf{presenza di sorgenti}, le equazioni di Maxwell assumono la forma:
\begin{align}
    \nabla \cdot \vec{E}(\vec{r},t) &= \frac{\rho}{\varepsilon} & \nabla \times \vec{E}(\vec{r},t) &= - \partial_t \vec{B}(\vec{r},t) \\
    \nabla \cdot \vec{B}(\vec{r},t) &= 0 & \nabla \times \vec{B}(\vec{r},t) &= \mu \left\{ \vec{J}(\vec{r},t) + \varepsilon \partial_t \vec{E}(\vec{r},t) \right\}
\end{align}
Inoltre sono importanti da ricordare le seguenti relazioni:
\begin{align}
    \nabla \cdot \vec{J}(\vec{r},t) &= -\partial_t \rho \quad \text{(Equazione di continuità)} \\
    \vec{F} &= q(\vec{E} + \vec{v} \times \vec{B}) \quad \text{(Forza di Lorentz)}
\end{align}
In presenza di un materiale dielettrico:
\begin{equation}
    \vec{D} = \varepsilon_0 \varepsilon_r \vec{E} \qquad \vec{B} = \mu_0 \mu_r \vec{H}
\end{equation}

Se invece siamo in \textbf{assenza di sorgenti} ($\rho = 0$, $\vec{J} = 0$), le equazioni diventano:
\begin{align}
    \nabla \cdot \vec{E}(\vec{r},t) &= 0 & \nabla \times \vec{E}(\vec{r},t) &= - \partial_t \vec{B} \\
    \nabla \cdot \vec{B}(\vec{r},t) &= 0 & \nabla \times \vec{B}(\vec{r},t) &= \mu \varepsilon \partial_t \vec{E}
\end{align}
Possiamo ricavare l'equazione delle onde applicando il rotore alla terza equazione:
\begin{equation}
    \nabla \times (\nabla \times \vec{E}) = -\nabla^2 \vec{E} + \nabla(\cancelto{0}{\nabla \cdot \vec{E}}) = -\partial_t (\nabla \times \vec{B})
\end{equation}
Sostituendo il rotore di $\vec{B}$, otteniamo:
\begin{equation}
    \nabla^2 \vec{E} = \varepsilon_0 \mu_0 \partial_t^2 \vec{E}
\end{equation}
Eseguendo lo stesso procedimento per il campo magnetico si ottiene un risultato analogo:
\begin{equation}
    \begin{cases}
        \nabla^2 \vec{E} = \varepsilon_0 \mu_0 \partial_t^2 \vec{E} \\
        \nabla^2 \vec{B} = \varepsilon_0 \mu_0 \partial_t^2 \vec{B}
    \end{cases}
\end{equation}

\section{Onde elettromagnetiche e approssimazione Iconale}
La soluzione all'equazione d'onda per campi monocromatici è data da:
\begin{align}
    \vec{E}(\vec{r}, t) &= \vec{E}_0 e^{i(\vec{k} \cdot \vec{r} - \omega t)} \\
    \vec{B}(\vec{r}, t) &= \frac{\vec{E}_0}{c} e^{i(\vec{k} \cdot \vec{r} - \omega t)}
\end{align}
dove $\vec{k}$ è il vettore d'onda. Dalle equazioni di Maxwell è possibile ricavare inoltre le seguenti relazioni di ortogonalità:
\begin{equation}
    \vec{k} \cdot \vec{E}_0 = 0, \qquad \vec{k} \cdot \vec{B}_0 = 0, \qquad \vec{k} \times \vec{E}_0 = \omega \vec{B}_0
\end{equation}
Ottengo dunque $6$ equazioni scalari, ciascuna della forma generale:
\begin{equation}
    \nabla^2 v(\vec{r}, t) = \frac{1}{c^2} \partial_t^2 v(\vec{r}, t)
\end{equation}
la cui soluzione generale (tramite sovrapposizione) è:
\begin{equation}
    v(\vec{r}, t) = \int A(\omega) e^{i\omega t} v_0 e^{i \vec{k} \cdot \vec{r}} d\omega
\end{equation}
In questo modo la soluzione generale può essere espressa come un'onda con ampiezza dipendente dalla posizione e fase dipendente dalla posizione:
\begin{equation}
    v(\vec{r}, t) = A(\vec{r}) e^{-i k_0 S(\vec{r})}
\end{equation}
dove $k_0$ e $k_0 S(\vec{r}) = \text{costante}$ (superfici d'onda). Se supponiamo che l'ampiezza vari lentamente, possiamo sviluppare la funzione iconale $S$ in serie di Taylor nell'intorno di un punto $\vec{r}_0$:
\begin{align}
    A(\vec{r}) &\approx A(\vec{r}_0) \\
    S(\vec{r}, t) &\approx S(\vec{r}_0) + \nabla S(\vec{r}_0) \cdot (\vec{r} - \vec{r}_0)
\end{align}
Sviluppo in serie (Funzione iconale per approssimare le superfici d'onda come piani ortogonali alla direzione di propagazione):
\begin{equation}
    v(\vec{r}) \simeq A(\vec{r}_0) \exp{-i k_0 S(\vec{r}_0) - i k_0 \nabla S(\vec{r}_0) \cdot (\vec{r} - \vec{r}_0)}
\end{equation}
Definisco il vettore d'onda locale e l'indice di rifrazione $n(\vec{r})$:
\begin{equation}
    \vec{k}(\vec{r}) = k_0 \nabla S(\vec{r}) \quad e \quad n(\vec{r}) = |\nabla S(\vec{r})|
\end{equation}
Da cui il modulo del vettore d'onda: $k(\vec{r}) = |\vec{k}(\vec{r})| = k_0 |\nabla S(\vec{r})| = k_0 n(\vec{r})$.

Definisco \textit{cammino ottico} $l$ la seguente grandezza:
\begin{equation}
    l = \int_\gamma |\nabla S(\vec{r})| ds
\end{equation}
Vale la seguente disuguaglianza: il percorso più breve è quello a pendenza massima (ortogonale alle superfici d'onda), ovvero lungo le linee di flusso del gradiente:
\begin{equation}
    \int_\gamma |\nabla S(\vec{r})| ds \le \int_{\gamma'} |\nabla S(\vec{r})| ds
\end{equation}

\begin{definizione}[title={Principio di Fermat}]
Definita la variazione di una funzione $\delta l$, il Principio di Fermat afferma che la luce segue un percorso per il quale il cammino ottico è stazionario:
\begin{equation}
    \delta l = \delta \int_\gamma |n(\vec{r})| ds = 0
\end{equation}
\end{definizione}

Siano:
\begin{itemize}
    \item $u$: densità di energia elettromagnetica.
    \item $\vec{S}$: densità di flusso di energia (Vettore di Poynting).
\end{itemize}

Posso definire la variazione di energia elettromagnetica interna al volume come:
\begin{equation}
    \Delta E = \partial_t \left\{ \int_V u \, dV \right\} \Delta t
\end{equation}
In presenza di un lavoro esterno, la variazione di energia è data da:
\begin{equation}
    \Delta E = \partial_t \left\{ \oint_{\partial V} \vec{S} \cdot \hat{n} \, dA \right\} \Delta t + \left\{ \int_V \frac{\Delta L}{\Delta t} dV \right\} \Delta t
\end{equation}
dove il termine di lavoro meccanico sulle cariche è dato dalla forza di Lorentz:
\begin{equation}
    \frac{\Delta L}{\Delta t} = \vec{F} \cdot \vec{v} = \vec{E} \cdot \vec{J}(\vec{r}, t)
\end{equation}

La variazione di energia elettromagnetica nel volume, unita al bilancio dei flussi e del lavoro sulle cariche, ci dà:
\begin{equation}
    -\partial_t \int_V u \, dV = \int_A \vec{S} \cdot \hat{n} \, dA + \int_V \vec{E} \cdot \vec{J} \, dV
\end{equation}
Applicando il teorema della divergenza al primo termine sul lato destro:
\begin{equation}
    -\partial_t \int_V u \, dV = \int_V \nabla \cdot \vec{S} \, dV + \int_V \vec{E} \cdot \vec{J} \, dV \quad \implies \quad - \partial_t u - \nabla \cdot \vec{S} = \vec{E} \cdot \vec{J}
\end{equation}
Riscriviamo il termine $\vec{E} \cdot \vec{J}$ utilizzando la 4ª equazione di Maxwell:
\begin{equation}
    \vec{E} \cdot \vec{J} = \vec{E} \cdot \left( \frac{\nabla \times \vec{B}}{\mu_0} - \varepsilon_0 \partial_t \vec{E} \right) = \frac{\vec{E} \cdot (\nabla \times \vec{B})}{\mu_0} - \frac{\varepsilon_0}{2} \partial_t E^2
\end{equation}

Sfruttando l'identità vettoriale $\nabla \cdot (\vec{E} \times \vec{B}) = \vec{B} \cdot (\nabla \times \vec{E}) - \vec{E} \cdot (\nabla \times \vec{B})$, otteniamo:
\begin{equation}
    \vec{E} \cdot \vec{J} = - \frac{\nabla \cdot (\vec{E} \times \vec{B})}{\mu_0} + \frac{\vec{B} \cdot (\nabla \times \vec{E})}{\mu_0} - \frac{\varepsilon_0}{2} \partial_t E^2
\end{equation}
Sostituendo $\nabla \times \vec{E} = -\partial_t \vec{B}$ dal 3° postulato di Maxwell:
\begin{equation}
    \vec{E} \cdot \vec{J} = - \frac{\nabla \cdot (\vec{E} \times \vec{B})}{\mu_0} - \frac{1}{2\mu_0} \partial_t B^2 - \frac{\varepsilon_0}{2} \partial_t E^2
\end{equation}
Definendo il \textbf{Vettore di Poynting} come $\vec{S} = \frac{1}{\mu_0} (\vec{E} \times \vec{B})$ e la densità di energia $u_{em}$, la relazione diventa il teorema di Poynting:
\begin{equation}
    \vec{E} \cdot \vec{J} = - \nabla \cdot \vec{S} - \partial_t u_{em}
\end{equation}
Definiamo infine l'\textbf{Irradianza} di un'onda come la media temporale del modulo del vettore di Poynting:
\begin{equation}
    I = \langle |\vec{S}| \rangle = \frac{1}{\mu_0} \langle |\vec{E} \times \vec{B}| \rangle = \frac{1}{\mu_0 c} \langle |E|^2 \rangle
\end{equation}
Se considero un'onda piana monocromatica:
\begin{equation}
    I = \frac{\varepsilon_0 c}{2} |E|^2
\end{equation}



\section{Esperienza 1: Verifica dell'Irradianza di una sorgente puntiforme}

\subsection{Modello Teorico}

Per misurare la distanza effettiva $r$, si pone inizialmente a contatto il fotodiodo con la lampadina alla posizione $x_0$ (dove $x_0$ è la posizione iniziale del fotodiodo). La distanza reale per un generico punto $x$ del binario sarà corretta per il diametro della lampadina $D$ e la posizione del sensore (stimata a \qty{1}{\milli\metre} di profondità):
\begin{equation}
    r_i = (x_i - x_0) + \frac{D}{2} + \qty{1}{\milli\metre}
\end{equation}
(È fondamentale in fase di allineamento che il filamento e la finestra del fotodiodo siano esattamente alla stessa quota per evitare dislivelli, ovvero $h=0$).

L'errore associato a tale misura spaziale non è puramente casuale. Possiamo stimare l'errore sistematico di traslazione come $(\sigma_{x_0} + \sigma_{D/2} + \sigma_{1\text{mm}})$. Ignoriamo in prima approssimazione per il fit questi ultimi errori, poiché causano solo uno "shift" rigido della scala.
L'errore casuale dominante $\sigma_x$ è dato dalla larghezza della tacca sulla scala graduata (allineamento visivo dell'indice col carrello). Possiamo stimare la deviazione standard tramite una distribuzione uniforme (es. larghezza indice \qty{0.2}{\milli\metre}):
\begin{equation}
    \sigma_x \simeq \frac{0{,}2}{\sqrt{3}} \text{ mm}
\end{equation}
L'incertezza sulle ordinate (Voltaggio) è data invece dalla somma quadratica dell'errore di lettura del multimetro e dell'incertezza sulla fluttuazione di fondo: $\sigma_V = \sqrt{\sigma_{lett}^2 + \sigma_{fondo}^2}$.

\begin{nota}
\begin{itemize}
    \item \textbf{Saturazione e Mascheratura:} Si applica del nastro adesivo nero sul fotodiodo lasciando solo una piccola fessura centrale per ridurne l'area attiva. Bisogna regolare la tensione dell'alimentatore per trovare il giusto compromesso affinché il voltmetro \textit{non vada a fondo scala} (saturazione) a circa 3-5 cm dalla lampadina, mantenendo però un segnale netto a grandi distanze. \textbf{Regolata la tensione, non va più toccata né spenta la lampadina.}
    \item \textbf{Luce Ambientale (Segnale Netto):} Il segnale reale va calcolato come $V_i = V_{R,i} - V_{F,i}$. Si legge prima la tensione a luce diretta ($V_R$), poi si inserisce rapidamente un oscuratore ("monetina") per schermare solo il fascio diretto e si legge il fondo ($V_F$). \textbf{Non cambiare mai scala sul voltmetro} durante questa coppia di letture. La monetina dovrebbe essere inserita inizialmente a metà tra fotodiodo e lampadina; successivamente, spostando il fotodiodo, si dovranno provare diverse posizioni annotando la tensione di fondo in queste ultime (es. 3 misure di fondo) per poi farne una media. Per calcolare l'errore si dovrà fare la semidifferenza tra il valore massimo e il minimo divisa per $\sqrt{3}$; se le misure di fondo avranno sempre lo stesso valore, l'errore corrisponderà alla sensibilità (precisione) del voltmetro.
    \item \textbf{Campionamento Disomogeneo:} A brevi distanze (3-15 cm) si prendono molti punti ravvicinati (passi da 2-5 mm) per campionare l'alta pendenza; a medie e grandi distanze si allarga il passo a 5-10 cm verso fine binario.
\end{itemize}
\end{nota}

\subsection{Analisi Dati e Preparazione per ROOT}

\textbf{ATTENZIONE agli Errori nel Fit:} Per eseguire il fit (es. in ROOT), si assegna ai punti \textbf{solo} l'incertezza sulla coordinata $x_i$ (ovvero $\sigma_x$) e l'errore di lettura del voltmetro su $V_i$. \textbf{NON propagare subito $x_0$ e $D$} nei punti sperimentali, altrimenti si introdurrebbero false correlazioni che sballerebbero i risultati.

La funzione di \textbf{Fit 1} dovrà avere una forma del tipo:
\begin{equation}
    f(x) = \frac{A}{(x-B)^2} + C
\end{equation}
con $A, B, C$ parametri da stimare.
In particolare: $A \ne 0$. Il parametro $B$ stima lo shift spaziale residuo: a fit concluso, per verificare che sia compatibile con 0, dovremo confrontarlo \textbf{considerando finalmente gli errori comuni} $\sigma_{x_0}$ e $\sigma_{D/2}$. Anche l'offset di tensione $C$ deve risultare compatibile con 0 ($C \pm \sigma_C \simeq 0$).

Se le misure saranno state prese abbastanza bene, l'errore su C dovrebbe essere confrontabile con gli errori della tensione ($\sigma_V = \sqrt{\sigma_{lett}^2 + \sigma_{fondo}^2}$, anche se in realtà dovrebbe essere un po' più piccolo) e il valore $C \pm 2\sigma_C$ dovrebbe risultare compatibile con $0$.
Anche il parametro B dovrebbe essere compatibile con $0$, ma in questo caso la compatibilità andrà verificata tenendo conto della stima $B \pm \sigma_{B} \pm \sigma_{x_0} \pm \sigma_{D/2} \pm \sigma_{1\text{mm}}$.
Il parametro A, invece, rappresenta un fattore di scala che ci indica l'ampiezza (altezza) della curva da determinare.

Come prova ulteriore della dipendenza $1/r^2$, è richiesto eseguire un \textbf{Fit 2}, usando come parametri iniziali $A, B, C$ quelli ottenuti nel primo, e aggiungendo il parametro esponente $D$:
\begin{equation}
    f_2(x) = \frac{A}{(x-B)^D} + C
\end{equation}
verificando che l'esponente stimato sia compatibile con 2.

\section{Legge di riflessione}
Ricordiamo il principio di Fermat, il quale stabilisce che la luce segue il percorso per cui la variazione del cammino ottico è nulla (cammino stazionario, tipicamente un minimo):
\begin{equation}
    \delta l = \delta \int_\gamma n(\vec r) ds = 0 
\end{equation}
Da questo principio è possibile ricavare la nota \textit{legge di riflessione}. 

Consideriamo una superficie riflettente piana e un mezzo omogeneo con indice di rifrazione $n$. Sia $A$ una sorgente puntiforme posta a un'altezza $h_1$ rispetto al piano e $B$ il punto di arrivo, posto a un'altezza $h_2$. Fissando l'origine del sistema di riferimento sulla proiezione di $A$ sul piano, chiamiamo $x$ l'ascissa del punto in cui il raggio incide sulla superficie e $D$ la distanza orizzontale totale tra $A$ e $B$. 
Il raggio incide con un angolo $\theta_i$ rispetto alla normale della superficie e viene riflesso con un angolo $\theta_r$.

Il cammino ottico totale $l$ percorso dalla luce per andare da $A$ a $B$ è dato dalla somma dei due tratti rettilinei moltiplicati per l'indice di rifrazione $n$:
\begin{equation}
    l = n \sqrt{h_1^2 + x^2} + n \sqrt{h_2^2 + (D-x)^2} 
\end{equation}
Per il Principio di Fermat, imponiamo che la derivata del cammino ottico rispetto alla coordinata $x$ sia nulla:
\begin{equation}
    \frac{\partial l}{\partial x} = 0 \quad \implies \quad n \left[ \frac{x}{\sqrt{h_1^2 + x^2}} - \frac{D-x}{\sqrt{h_2^2 + (D-x)^2}} \right] = 0 
\end{equation}
Osservando la geometria del sistema, riconosciamo che i termini tra parentesi corrispondono esattamente ai seni degli angoli di incidenza e riflessione. Si ottiene quindi:
\begin{equation}
    n (\sin \theta_i - \sin \theta_r) = 0 \quad \implies \quad \theta_i = \theta_r
\end{equation}
ovvero l'angolo di incidenza è uguale all'angolo di riflessione.

Con un ragionamento del tutto analogo, applicato però a un fenomeno di \textbf{trasmissione} tra due mezzi trasparenti con indici di rifrazione diversi ($n_1$ e $n_2$), possiamo ricavare la \textit{legge di rifrazione (o Legge di Snell)}. In questo caso, il cammino ottico diventa:
\begin{equation}
    l = n_1 \sqrt{h_1^2 + x^2} + n_2 \sqrt{h_2^2 + (D-x)^2}
\end{equation}
Derivando e uguagliando a zero, otteniamo:
\begin{equation}
    \frac{\partial l}{\partial x} = 0  \quad \implies \quad n_1 \sin \theta_1 = n_2 \sin \theta_2
\end{equation}

Da questa relazione emerge un limite fisico interessante. Se la luce passa da un mezzo più denso a uno meno denso ($n_1 > n_2$), avremo che $\frac{n_1}{n_2} > 1$. Esisterà quindi un certo angolo di incidenza per cui la formula fornirebbe $\sin \theta_2 = \frac{n_1}{n_2} \sin \theta_1 > 1$, il che è matematicamente impossibile. 
Ciò significa che per angoli di incidenza superiori a un certo valore critico, la luce non viene più trasmessa ma subisce una \textit{riflessione totale interna}. Questo \textbf{angolo limite} $\theta_c$ è definito dalla condizione $\sin \theta_2 = 1$ (angolo di uscita radente di $90^\circ$):
\begin{equation}
    \sin \theta_c = \frac{n_2}{n_1}
\end{equation}

\section{Equazione delle lenti sottili}

Vogliamo ora modellare il comportamento di una lente sferica immersa in un mezzo omogeneo. Supponiamo che la lente abbia un indice di rifrazione $n_2$, raggi di curvatura $R_1$ e $R_2$ e sia immersa in un mezzo con indice $n_1$ (ad esempio aria, $n_{aria} = 1.0003$). 

Sia $O$ una sorgente puntiforme posta sull'asse ottico. Un raggio di luce parte da $O$, entra nella lente nel punto $L_1$, esce nel punto $L_2$ e viene focalizzato in un punto immagine $I$, anch'esso sull'asse ottico. Siano $C_1$ e $C_2$ i vertici delle calotte sferiche della lente (i punti di intersezione con l'asse ottico). 
Definiamo le seguenti grandezze geometriche:
\begin{itemize}
    \item $p$: distanza tra l'oggetto $O$ e la superficie frontale $C_1$.
    \item $q$: distanza tra la superficie posteriore $C_2$ e l'immagine $I$.
    \item $\Delta$: spessore della lente lungo l'asse ottico (distanza tra $C_1$ e $C_2$).
    \item $\Delta_1, \Delta_2$: distanze orizzontali (profondità) tra i piani passanti per i vertici e i punti di incidenza $L_1, L_2$.
    \item $h_1, h_2$: altezze (distanze dall'asse ottico) dei punti di incidenza $L_1$ e $L_2$.
\end{itemize}

Il principio alla base della formazione delle immagini (stigmatismo) impone che i fronti d'onda sferici emessi da $O$ debbano riconvergere, mantenendosi sferici, nel punto $I$. Affinché questo avvenga, tutti i possibili percorsi ottici tra $O$ e $I$ devono essere uguali, ovvero in fase tra loro. In particolare, il cammino ottico assiale (quello che attraversa il centro della lente) deve uguagliare il cammino del raggio marginale generico che incide ad altezza $h$:
\begin{equation}
    l_{O \to C_1 \to C_2 \to I} = l_{O \to L_1 \to L_2 \to I}
\end{equation}

\subsection{Approssimazioni}
Per risolvere matematicamente il sistema, applichiamo due semplificazioni fondamentali:
\begin{enumerate}
    \item \textbf{Approssimazione dei raggi parassiali}: $p,q \gg h_1, h_2$. I raggi si mantengono molto vicini all'asse ottico.
    \item \textbf{Approssimazione della lente sottile}: $p,q \gg R_1, R_2 \gg h_1, h_2$. Lo spessore della lente è trascurabile rispetto alle altre distanze in gioco. Di conseguenza, il raggio all'interno della lente non subisce deviazioni verticali significative, permettendoci di assumere $h_1 \simeq h_2 = h$.
\end{enumerate}

Scriviamo i due cammini ottici:
\begin{align}
     l_{\text{assiale}} &= n_1 p + n_2 (\Delta_1 + \Delta_2 + \Delta) + n_1 q \\
     l_{\text{marginale}} &= n_1 \sqrt{(p+\Delta_1)^2 + h^2} + n_2 \Delta + n_1 \sqrt{(q+\Delta_2)^2 + h^2}
\end{align}
Essendo in regime parassiale, possiamo utilizzare l'espansione di Taylor per le radici $\sqrt{a^2 + b^2} \simeq a \left(1 + \frac{b^2}{2a^2}\right) = a + \frac{b^2}{2a}$ (valida per $b \ll a$). Sapendo inoltre che $h \ll p$ e $h \ll q$, possiamo approssimare $(p+\Delta_1) \simeq p$ al denominatore:
\begin{equation}
     l_{\text{marginale}} \simeq n_1 \left( (p+\Delta_1) + \frac{h^2}{2p} \right) + n_2 \Delta + n_1 \left( (q+\Delta_2) + \frac{h^2}{2q} \right)
\end{equation}    
Uguagliando i due percorsi ($l_{\text{assiale}} = l_{\text{marginale}}$), otteniamo:
\begin{equation}
     n_1 \left( \Delta_1 + \frac{h^2}{2p} \right) - n_2 (\Delta_1 + \Delta_2) + n_1 \left( \Delta_2 + \frac{h^2}{2q} \right) = 0
\end{equation}
Raccogliendo i termini, arriviamo all'espressione:
\begin{equation}
     n_1 \left( \frac{h^2}{2p} + \frac{h^2}{2q} \right) = (n_2 - n_1) (\Delta_1 + \Delta_2)
     \label{eq:dimostrazione_lenti1}
\end{equation}  

Ora calcoliamo geometricamente i termini di spessore $\Delta_1$ e $\Delta_2$ delle calotte sferiche. Considerata una circonferenza di raggio $R$ tagliata a un'altezza $h$, la profondità della calotta (freccia) è $\Delta = R - \sqrt{R^2 - h^2}$. Sfruttando nuovamente Taylor per $h \ll R$:
\begin{equation}
    \Delta = R - R \sqrt{1 - \left(\frac{h}{R}\right)^2} \simeq R - R \left( 1 - \frac{h^2}{2R^2} \right) = \frac{h^2}{2R}
\end{equation} 
Sostituendo $\Delta_1 = \frac{h^2}{2R_1}$ e $\Delta_2 = \frac{h^2}{2R_2}$ nell'equazione \ref{eq:dimostrazione_lenti1} e semplificando per il termine comune $h^2/2$, otteniamo la celebre \textbf{Equazione dei costruttori di lenti}:
\begin{equation}
     \frac{1}{p} + \frac{1}{q} = \frac{n_2 - n_1}{n_1} \left( \frac{1}{R_1} + \frac{1}{R_2} \right)
\end{equation}
Questa equazione lega il comportamento ottico (coniugazione tra oggetto in $p$ e immagine in $q$) alle caratteristiche fisiche e costruttive della lente ($R_1, R_2, n_2$). 
Se definiamo la \textit{lunghezza focale} $f$ del sistema come: 
\begin{equation}
    \frac{1}{f} = \frac{n_2 - n_1}{n_1}\left(\frac{1}{R_1} + \frac{1}{R_2}\right)
\end{equation} 
ritroviamo la fondamentale \textbf{Legge delle lenti sottili}:
\begin{equation}
    \frac{1}{p} + \frac{1}{q} =  \frac{1}{f}
\end{equation}

\subsection{Casistiche e Applicazioni}

L'equazione restituisce $\frac{1}{\infty} + \frac{1}{q} = \frac{1}{f}$, da cui si ottiene $q = f$. L'immagine si forma esattamente sul piano focale.

È possibile tuttavia realizzare lenti \textit{divergenti} aventi facce concave ($R_1, R_2 < 0$). Inserendo raggi di curvatura negativi nell'equazione dei costruttori di lenti, otteniamo una focale $f$ negativa.
    
    Fisicamente, una focale negativa implica che un fascio di luce parallelo incidente sulla lente, anziché concentrarsi, tenderà ad aprirsi allargandosi. In questo caso il fuoco è "virtuale": prolungando all'indietro i raggi uscenti divergenti, essi sembrano provenire da un punto situato *prima* della lente.

Il termine $(n_2 - n_1)$ diventerà negativo, trasformando la lente convergente in divergente (un classico esempio è una bolla d'aria all'interno dell'acqua).

Il legame tra le coordinate di ingresso $(y_1, \theta_1)$ e quelle di uscita $(y_2, \theta_2)$ è dato da una combinazione lineare:
\begin{equation}
    \begin{cases}
        y_2 = A y_1 + B \theta_1 \\
        \theta_2 = C y_1 + D \theta_1
    \end{cases}
\end{equation}
Questa relazione può essere riscritta in forma matriciale come:
\begin{equation}
\begin{pmatrix}
y_2 \\
\theta_2
\end{pmatrix}
=
\begin{pmatrix}
A & B \\
C & D
\end{pmatrix}
\begin{pmatrix}
y_1 \\
\theta_1
\end{pmatrix}
\end{equation}

Inoltre, se introduciamo il \textit{raggio di curvatura del fronte d'onda} associato, definito in approssimazione parassiale come $R = \frac{y}{\theta}$, possiamo esprimere il raggio di curvatura in uscita in funzione di quello in ingresso:
\begin{equation}
    \begin{cases}
        R_2 \theta_2 = A R_1 \theta_1 + B \theta_1 \\
        \theta_2 = C R_1 \theta_1 + D \theta_1
    \end{cases}
\end{equation}
Dividendo membro a membro, otteniamo la legge di trasformazione del raggio di curvatura da parte del sistema ottico:
\begin{equation}
    R_2 = \frac{A R_1 + B}{C R_1 + D}
\end{equation}

\end{equation}

Dalla geometria del sistema, e ricordando che $\tan \theta \approx \theta$, possiamo legare gli angoli alle distanze dell'oggetto e dell'immagine. Ponendo attenzione ai segni (il raggio emerge inclinato verso il basso), si ha:
\begin{equation}
    \theta_1 \approx \frac{y_1}{p} \qquad \text{e} \qquad \theta_2 \approx - \frac{y_1}{q}
\end{equation}
Richiamando l'equazione delle lenti sottili $\left(\frac{1}{p} + \frac{1}{q} = \frac{1}{f}\right)$ e moltiplicando tutto per l'altezza $y_1$, otteniamo:
\begin{equation}
    \frac{y_1}{p} + \frac{y_1}{q} = \frac{y_1}{f} \quad \implies \quad \theta_1 - \theta_2 = \frac{y_1}{f}
\end{equation}
Essendo la lente "sottile", l'altezza di uscita è identica a quella di ingresso ($y_2 = y_1$). Il sistema di equazioni diventa quindi:
\begin{equation}
    \begin{cases}
        y_2 = y_1 \\
        \theta_2 = -\frac{1}{f} y_1 + \theta_1
    \end{cases}
\end{equation}
Da cui si ricava la matrice di trasferimento della lente sottile:
\begin{equation}
    M = 
    \begin{pmatrix}
        1 & 0 \\ 
       -\frac{1}{f} & 1
    \end{pmatrix}
\end{equation}

Il percorso della luce si divide in tre fasi: l'attraversamento della prima lente, il trasporto nello spazio libero per una distanza $d$, e infine l'attraversamento della seconda lente. La matrice totale si calcola come $M_{\text{tot}} = M_{L2} \cdot M_{d} \cdot M_{L1}$:
\begin{equation}
M_{\text{tot}} = 
\begin{pmatrix}
    1 & 0 \\ 
    -\frac{1}{f_2} & 1   
\end{pmatrix}     
\begin{pmatrix}
    1 & d \\ 
    0 & 1   
\end{pmatrix}
\begin{pmatrix}
    1 & 0 \\ 
    -\frac{1}{f_1} & 1   
\end{pmatrix}
\end{equation}
Eseguendo il prodotto tra matrici otteniamo:
\begin{equation}
M_{\text{tot}} = 
\begin{pmatrix}
    1 - \frac{d}{f_1} & d \\[1ex]
    -\frac{1}{f_1} - \frac{1}{f_2} + \frac{d}{f_1 f_2} & 1 - \frac{d}{f_2}   
\end{pmatrix}   
\end{equation}
Analogamente a quanto visto per la matrice della lente sottile singola, l'elemento in basso a sinistra rappresenta la potenza ottica del sistema cambiato di segno ($-1/f_{\text{tot}}$). Da questo ricaviamo l'espressione generale:
\begin{equation}
    \frac{1}{f_{\text{tot}}} = \frac{1}{f_1} + \frac{1}{f_2} - \frac{d}{f_1 f_2}
\end{equation}
Se poniamo le lenti a contatto perfetto ($d=0$), il termine misto si annulla e ritroviamo la nota regola di addizione delle potenze ottiche $\left(\frac{1}{f_{\text{tot}}} = \frac{1}{f_1} + \frac{1}{f_2}\right)$.

\subsubsection{Lente Spessa}
Possiamo rimuovere l'ipotesi di lente sottile e calcolare la matrice completa per una lente avente uno spessore finito $d$, composta da un materiale con indice $n_2$ (con raggi di curvatura frontale $R_1$ e posteriore $R_2$), immersa in un mezzo esterno $n_1$. 

In questo caso, il sistema è schematizzabile come la successione di un'interfaccia sferica (ingresso), un trasporto nel mezzo con indice $n_2$ per una distanza $d$, e una seconda interfaccia sferica (uscita):
\begin{equation}
    M_{\text{tot}} = M(R_2) \cdot M_d \cdot M(R_1)
\end{equation}
La matrice risultante assumerà la forma generale:
\begin{equation}
    M_{\text{tot}} = 
    \begin{pmatrix}
        1 - \frac{d_2}{f} & d \frac{n_1}{n_2} \\[1ex]
        -\frac{1}{f} & 1 - \frac{d_1}{f}
    \end{pmatrix}
\end{equation}
dove $d_1$ e $d_2$ indicano la posizione dei cosiddetti "piani principali" della lente rispetto ai suoi vertici fisici. La distanza focale effettiva $f$ della lente spessa (determinabile ricavando l'elemento in basso a sinistra della matrice) è data dall'\textit{Equazione di Gullstrand}:
\begin{equation}
    \frac{1}{f} = \frac{n_2 - n_1}{n_1} \left[ \frac{1}{R_1} - \frac{1}{R_2} + \frac{(n_2 - n_1) d}{n_2 R_1 R_2} \right]
\end{equation}
Questa espressione estende l'equazione dei costruttori di lenti aggiungendo un termine correttivo dipendente dallo spessore $d$. Se $d \to 0$, il termine correttivo scompare e si ritorna al caso della lente sottile.

\subsection{Misura operativa delle distanze $p$ e $q$}
Sul banco ottico leggiamo le coordinate spaziali dei supporti ($x$ per la lente, $y$ per lo schermo), che non corrispondono direttamente alle distanze ottiche $p$ e $q$ a causa degli ingombri fisici dei supporti stessi, i quali impediscono di far coincidere i centri ottici.

Per ricavare $p$ utilizziamo una procedura di calibrazione con una barretta di lunghezza nota $L$ (misurata preventivamente con un calibro). Portando il supporto della lente a battuta contro la barretta (appoggiata al supporto della lampadina), leggiamo sul binario una coordinata di riferimento $x_0$ (posizione della lente). In questa configurazione, sappiamo che la distanza ottica reale tra lente e lampadina è pari alla lunghezza della barretta più la metà dello spessore del supporto della lente ($D/2$). Quando spostiamo la lente in una generica posizione $x$, la distanza oggetto $p$ sarà data da:
\begin{equation}
    p = (x - x_0) + L + \frac{D}{2}
\end{equation}

In modo analogo calibriamo $q$. Mantenendo la lente nella posizione $x_0$, interponiamo la barretta $L$ tra la lente e lo schermo. La coordinata letta per lo schermo sarà $y_0$ e in tale configurazione la distanza ottica è esattamente $L$. In una configurazione generica, allontanando lo schermo in $y$ si ha un contributo positivo $(y - y_0)>0$, mentre allontanando la lente in $x$ la distanza $q$ diminuisce, introducendo un contributo negativo $-(x - x_0)<0$. Complessivamente la distanza immagine $q$ è:
\begin{equation}
    q = (y - y_0) + L - (x - x_0)
\end{equation}

\subsection{Procedura di misura e gestione delle incertezze}
È fisicamente impossibile ottenere un'immagine se $p < f$, pertanto la presa dati deve iniziare per distanze maggiori della focale. Per trovare operativamente il punto di partenza, posizioniamo lo schermo alla distanza massima consentita dal binario e spostiamo la lente fino a trovare la prima messa a fuoco utile. All'inizio (lente vicina alla lampada) la curva teorica è molto ripida: procederemo quindi spostando la lente a passi piccoli (es. $1 \text{ mm}$). Avanzando lungo il binario, lo schermo camminerà verso di noi, finché non si supererà il punto simmetrico; da lì in poi $q$ resterà circa costante. 

Il processo di messa a fuoco consiste nel cercare sul foglio l'immagine nitida e capovolta del filamento della lampadina. Operativamente, ad ogni step \textit{fissiamo la lente} allineandola accuratamente alla tacca del binario (rendendo l'errore su $x$ trascurabile, derivante solo dalla lettura e pari a $\sigma_x = \frac{0,2}{\sqrt{3}}$) e \textit{muoviamo lo schermo} ($y$) finché l'immagine appare a fuoco. 
In questo modo, l'errore significativo risiede interamente sulla misura di $y$ (profondità di fuoco). Se adottassimo la strategia opposta (fissare lo schermo e muovere la lente per mettere a fuoco), commetteremmo un grave errore di analisi: un'incertezza su $x$ si propagherebbe sia su $p$ che su $q$ (a causa del segno $-$ nella formula di $q$), introducendo una forte anticorrelazione degli errori molto difficile da gestire. 

L'incertezza $\sigma_y$ associata alla messa a fuoco non è costante durante l'esperienza. È determinata dall'intervallo spaziale all'interno del quale l'immagine appare soggettivamente nitida. Quando la lente è vicina alla lampadina e lo schermo è molto lontano, i raggi che convergono sullo schermo incidono con angoli molto piccoli (sono quasi paralleli); di conseguenza, anche spostando lo schermo di molto, la dimensione della macchia luminosa varia impercettibilmente, causando una $\sigma_y$ molto grande. Al contrario, nella configurazione quasi simmetrica (lente a metà strada), i raggi incidono con un angolo maggiore e il minimo spostamento dello schermo sfoca immediatamente l'immagine, rendendo la misura molto più precisa.

\subsection{Modello di fit e ricerca della focale}
Proprio a causa della complessa propagazione degli errori sistematici (su $x_0$, $L$, $y_0$, $D/2$), in fase preliminare trascuriamo questi ultimi ed eseguiamo il fit direttamente sulle coordinate di lettura $x$ e $y$. Riscriviamo l'equazione delle lenti sottili come:
\begin{equation}
    \frac{1}{x-A} + \frac{1}{y-B} = \frac{1}{C}
\end{equation}
Esplicitando l'equazione per $y$ otteniamo la funzione da utilizzare nel software di fit:
\begin{equation}
    y = B + \frac{C(x-A)}{(x-A) - C}
\end{equation}
Il significato fisico dei parametri stimati dal fit è il seguente:
\begin{itemize}
    \item $C$ rappresenta direttamente la lunghezza focale $f$ stimata dal sistema.
    \item $A$ rappresenta lo spostamento del riferimento sulle ascisse. Ci aspettiamo che sia compatibile con zero (entro le incertezze).
    \item $B$ rappresenta lo spostamento del riferimento sulle ordinate (dove dovrebbe trovarsi la divergenza asintotica). Anche in questo caso ci si aspetta la compatibilità con zero.
\end{itemize}

L'errore finale sulla distanza focale sarà semplicemente $\sigma_C$ restituito dal fit. Per verificare la compatibilità di $A$ e $B$ con zero, dovremo invece sommare all'errore statistico del fit gli errori sistematici della calibrazione precedentemente trascurati:
\begin{align*}
    \Delta A &= \sigma_A + \sigma_{x_0} + \sigma_{\frac{D}{2}} + \sigma_L \\
    \Delta B &= \sigma_B + \sigma_{y_0} + \sigma_L
\end{align*}
(Notiamo che in $\Delta B$ è corretto trascurare l'errore di posizionamento su $x_0$).\

\subsection{Modello di Lorentz per l'indice di rifrazione}

Si applica tipicamente al caso di gas rarefatti (mezzi dielettrici), dove è lecito trascurare l'interazione reciproca tra le molecole del gas stesso. 

Si consideri un mezzo gassoso contenente $N$ atomi (o molecole) per unità di volume. Concentriamoci per ora su un singolo elettrone di carica $q = -e$ per ogni atomo. Se a causa di un campo esterno gli elettroni vengono spostati di una distanza $\mathbf{r}$ rispetto alla loro posizione di equilibrio, si genera una polarizzazione macroscopica del mezzo pari a:
\begin{equation}
    \mathbf{P} = - N e \mathbf{r}
\end{equation}

Se questo spostamento è causato da un campo elettrico statico $\mathbf{E}$ applicato a tutto il mezzo e lo spostamento è sufficientemente piccolo, l'elettrone subisce una forza elettrica $\mathbf{F}_{\text{el}} = -e \mathbf{E}$. Essendo vicino al minimo del potenziale, l'elettrone è soggetto a una forza di richiamo (modellizzata come) elastica $\mathbf{F}_{\text{el}} = -k \mathbf{r}$. 
All'equilibrio, le due forze si bilanciano ($-e \mathbf{E} = k \mathbf{r}$), da cui si ricava lo spostamento $\mathbf{r} = -\frac{e}{k} \mathbf{E}$. Sostituendo questo risultato nell'espressione della polarizzazione otteniamo:
\begin{equation}
    \mathbf{P} = \frac{N e^2}{k} \mathbf{E}
\end{equation}

Nel caso in cui il campo elettrico non sia statico ma oscillante, l'elettrone si comporterà come un oscillatore armonico smorzato. Introduciamo quindi l'equazione del moto tenendo conto di un termine dissipativo (dovuto all'attrito e alla radiazione emessa dal dipolo oscillante):
\begin{equation}
    m \frac{d^2\mathbf{r}}{dt^2} + m \gamma \frac{d\mathbf{r}}{dt} + m \omega_0^2 \mathbf{r} = -e \mathbf{E}
\end{equation}
dove:
\begin{itemize}
    \item $\gamma$ è la costante di smorzamento (dispersiva);
    \item $m \gamma \frac{d\mathbf{r}}{dt}$ è la forza viscosa proporzionale alla velocità dell'elettrone;
    \item $\omega_0 = \sqrt{\frac{k}{m}}$ è la frequenza di risonanza naturale dell'oscillatore.
\end{itemize}

Assumendo che il campo $\mathbf{E}$ sia generato da un'onda elettromagnetica, esso oscillerà con legge armonica $\mathbf{E} \propto e^{- i \omega t}$. Di conseguenza, anche lo spostamento $\mathbf{r}$ avrà un andamento del tipo $\mathbf{r} \propto e^{- i \omega t}$. Calcolando le derivate temporali (che equivalgono a moltiplicare per $-i\omega$), l'equazione differenziale diventa un'equazione algebrica:
\begin{equation}
    (-m\omega^2 - i\omega m\gamma + m\omega_0^2)\mathbf{r} = -e\mathbf{E}
\end{equation}
Isolando lo spostamento $\mathbf{r}$ e sostituendolo nella definizione di polarizzazione $\mathbf{P} = -N e \mathbf{r}$, si ottiene la polarizzazione dinamica del mezzo:
\begin{equation}
    \mathbf{P} = \frac{N e^2/m}{\omega_0^2 - \omega^2 - i\omega \gamma} \mathbf{E}
\label{eq:polarizzazione_dinamica}
\end{equation}

Per capire come questa polarizzazione influisca sulla propagazione della luce, ricordiamo le equazioni di Maxwell per i mezzi materiali:
\begin{equation}
    \begin{cases}
        \nabla \times \mathbf{E}  = - \mu_0 \frac{\partial \mathbf{H}}{\partial t}\\
        \nabla \times \mathbf{H} = \frac{\partial \mathbf{D}}{\partial t} + \mathbf{J} \\
        \nabla \cdot \mathbf{D} = \rho \\
        \nabla \cdot \mathbf{B} = 0
    \end{cases}
\end{equation}

Applicando l'operatore rotore ($\nabla \times$) alla prima equazione otteniamo l'equazione delle onde. Sfruttando l'identità vettoriale $\nabla \times (\nabla \times \mathbf{E}) = \nabla(\nabla \cdot \mathbf{E}) - \nabla^2 \mathbf{E}$ e considerando le ipotesi del nostro sistema fisico (gas perfetto senza cariche o correnti libere, quindi $\mathbf{J}=0$ e $\rho=0 \implies \nabla \cdot \mathbf{E} = 0$), l'equazione si semplifica in:
\begin{equation}
    -\nabla^2 \mathbf{E} = - \mu_0 \frac{\partial}{\partial t} \left( \frac{\partial \mathbf{D}}{\partial t} \right)
\end{equation}
Ricordando che $\mathbf{D} = \varepsilon_0 \mathbf{E} + \mathbf{P}$, si ricava:
\begin{equation}
    \nabla^2 \mathbf{E} = \mu_0 \varepsilon_0 \frac{\partial^2 \mathbf{E}}{\partial t^2} + \mu_0 \frac{\partial^2 \mathbf{P}}{\partial t^2}
\end{equation}
Sostituendo l'espressione di $\mathbf{P}$ trovata nell'Equazione \ref{eq:polarizzazione_dinamica} e ricordando che $\mu_0 \varepsilon_0 = 1/c^2$, si può raccogliere a fattor comune la derivata temporale (essendo sia $\mathbf{P}$ che $\mathbf{E}$ proporzionali a $e^{-i\omega t}$):
\begin{equation}
    \nabla^2 \mathbf{E} = \frac{1}{c^2} \frac{\partial^2 \mathbf{E}}{\partial t^2} \left( 1 + \frac{N e^2}{\varepsilon_0 m} \frac{1}{\omega_0^2 - \omega^2 - i\omega \gamma} \right)
\end{equation}
Questa è l'equazione delle onde $\nabla^2 \mathbf{E} = \frac{n^2}{c^2} \frac{\partial^2 \mathbf{E}}{\partial t^2}$, dove il termine tra parentesi rappresenta proprio il quadrato dell'indice di rifrazione complesso:
\begin{equation}
    n^2 = 1 + \frac{N e^2}{\varepsilon_0 m} \frac{1}{\omega_0^2 - \omega^2 - i\omega \gamma}
\end{equation}

Questa formula ci mostra che l'indice di rifrazione dipende dalla frequenza $\omega$ dell'onda incidente, ed è caratterizzato da un profilo risonante. L'effetto sulla propagazione sarà massimo quando la frequenza dell'onda è vicina alla frequenza di risonanza del mezzo ($\omega \approx \omega_0$). 
Inoltre, $n$ è una quantità complessa ($n = \text{Re}[n] + i \text{Im}[n]$).

Per comprendere il significato di $n$, consideriamo la propagazione del campo elettrico lungo l'asse $z$: $\mathbf{E} = \mathbf{E}_0 e^{i(k z - \omega t)}$. Sapendo che $k = n \frac{\omega}{c} = (\text{Re}[n] + i \text{Im}[n]) k_0$, l'equazione dell'onda si riscrive come:
\begin{equation}
    \mathbf{E}(z,t) = \mathbf{E}_0 e^{- \text{Im}[n] k_0 z} e^{i(\text{Re}[n] k_0 z - \omega t)}
\end{equation}
Il termine reale determina la velocità di fase dell'onda, mentre il termine $e^{- \text{Im}[n] k_0 z}$ (strettamente reale e decrescente) rappresenta un decadimento esponenziale dell'ampiezza. La parte immaginaria dell'indice di rifrazione è quindi direttamente responsabile dell'assorbimento dell'onda man mano che si propaga, un fenomeno dovuto alla dissipazione di energia (attrito/calore o diffusione) nel mezzo.

Nella realtà atomica, un atomo possiede più elettroni distribuiti in diversi orbitali (gusci energetici), ciascuno caratterizzato da una diversa costante elastica e, di conseguenza, da una diversa frequenza di risonanza $\omega_j$. 
Per tenere conto di questo, si introduce una sommatoria pesata sulle varie frequenze di risonanza, dove $f_j$ rappresenta la frazione di elettroni associata all'energia di legame $j$-esima:
\begin{equation}
        n^2 = 1 + \frac{N e^2}{\varepsilon_0 m} \sum_{j}  \frac{f_j}{\omega_j^2 - \omega^2 - i\omega \gamma_j}
\end{equation}

\begin{nota}[title=Considerazioni finali sul modello]
Riguardo al modello appena derivato è importante sottolineare due aspetti fondamentali:
\begin{enumerate}
    \item \textbf{Il ruolo del nucleo atomico:} Nel nostro calcolo abbiamo considerato solo la dinamica degli elettroni, trascurando il fatto che anche i nuclei potrebbero spostarsi sotto l'azione del campo elettrico. Questa approssimazione è comunque buona perché la massa compare al denominatore nell'espressione della polarizzazione. Essendo la massa del protone molto più grande di quella dell'elettrone ($m_p \sim 2000 \, m_e$), il contributo dei nuclei alla polarizzazione macroscopica è del tutto trascurabile alle frequenze ottiche.
    \item \textbf{Dipendenza dalla densità $N$ e limiti del modello:} L'indice di rifrazione cresce linearmente con $N$ (numero di atomi per volume). Questo è vero solo per valori piccoli di $N$ (mezzi rarefatti). Se la densità aumenta troppo (liquidi, solidi o gas densi), le interazioni molecolari non sono più trascurabili. Il campo elettrico percepito dal singolo atomo non è più solo quello dell'onda incidente, ma include anche il campo generato dai dipoli circostanti, i quali si oppongono parzialmente al campo originale smorzando la polarizzazione complessiva (modello di Lorentz-Lorenz). Nonostante ciò, la formula empirica di Sellmeier si adatta perfettamente anche ai mezzi densi, poiché questi effetti microscopici complessi vengono "assorbiti" all'interno dei coefficienti sperimentali $A_i$.
\end{enumerate}
\end{nota}

\section{Esperienza 3: Calcolo di $n$ partendo dal modello di Sellmeier}

Lo scopo di questa esperienza è misurare l'indice di rifrazione di un prisma di vetro al variare della lunghezza d'onda e verificare se l'andamento sperimentale segue l'equazione di Sellmeier ricavata teoricamente:
\begin{equation}
    n^2(\lambda) = 1 + \frac{A \lambda^2}{\lambda^2 - \lambda_0^2}
\end{equation}
L'analisi dati consisterà nell'estrarre i parametri incogniti $A$ e $\lambda_0$ tramite un fit non lineare.

\subsection{Teoria: Prisma e angolo di deviazione minima}
Per poter calcolare l'indice di rifrazione $n$ del vetro, sfrutteremo il fenomeno della rifrazione attraverso un prisma. 

Si consideri un prisma avente un angolo al vertice $\alpha$. Un fascio di luce incide sulla faccia sinistra con un angolo $\theta_1$ rispetto alla normale, viene rifratto all'interno del prisma con un angolo $\theta_1'$, viaggia fino alla faccia destra dove incide con un angolo $\theta_2'$ e infine emerge nell'aria con un angolo $\theta_2$.

Dalla geometria del sistema, l'angolo di deviazione totale è la somma delle deviazioni subite sulle due interfacce:
\begin{equation}
    \delta = (\theta_1 - \theta_1') + (\theta_2 - \theta_2') = \theta_1 + \theta_2 - (\theta_1' + \theta_2')
\end{equation}
Considerando il triangolo formato dal vertice del prisma e dalle normali alle facce, la somma degli angoli interni ci fornisce la relazione tra l'angolo al vertice $\alpha$ e gli angoli di rifrazione interni:
\begin{equation}
    \alpha = \pi - \left(\frac{\pi}{2} - \theta_1'\right) - \left(\frac{\pi}{2} - \theta_2' \right) = \theta_1' + \theta_2'
\end{equation}
Sostituendo $\alpha$ nell'espressione precedente si ottiene la formula generale per la deviazione:
\begin{equation}
    \delta = \theta_1 + \theta_2 - \alpha
\label{eq:deviazione}
\end{equation}
Gli angoli sulle due facce sono inoltre legati dalla legge di Snell:
\begin{equation}
    \begin{cases}
        \sin \theta_1 = n \sin \theta_1' \\
        \sin \theta_2 = n \sin \theta_2'
    \end{cases}
\label{eq:snell_prisma}
\end{equation}

In laboratorio cercheremo la condizione di \textbf{deviazione minima} ($\delta_{\text{min}}$). Matematicamente, questo avviene quando la derivata di $\delta$ rispetto all'angolo di incidenza $\theta_1$ è nulla:
\begin{equation}
    \frac{d \delta}{d \theta_1}= 1 + \frac{d \theta_2}{d \theta_1}= 0 \quad \implies \quad \frac{d \theta_2}{d \theta_1} = -1
\end{equation}
Questo significa che, nell'intorno del minimo, se $\theta_1$ aumenta, $\theta_2$ diminuisce della stessa quantità. Differenziando le equazioni di Snell (\ref{eq:snell_prisma}) otteniamo:
\begin{equation}
    \begin{cases}
        \cos \theta_1 \, d\theta_1 = n \cos \theta_1' \, d\theta_1' \\
        \cos \theta_2 \, d\theta_2 = n \cos \theta_2' \, d\theta_2'
    \end{cases}
    \quad \implies \quad 
    \frac{d\theta_1'}{d\theta_2'} \frac{\cos \theta_1'}{\cos \theta_2'} = \frac{d\theta_1}{d\theta_2} \frac{\cos \theta_1}{\cos \theta_2}
\end{equation}
Poiché $\alpha = \theta_1' + \theta_2'$ è costante, differenziando si ha $d\theta_1' = - d\theta_2'$, ovvero $\frac{d\theta_1'}{d\theta_2'} = -1$. Sostituendo questa condizione e sapendo che $\frac{d \theta_2}{d \theta_1} = -1$, la relazione precedente diventa:
\begin{equation}
   \frac{\cos \theta_1'}{\cos \theta_2'} = \frac{\cos \theta_1}{\cos \theta_2} \quad \implies \quad \cos \theta_1 \cos \theta_2' = \cos \theta_2 \cos \theta_1'
\end{equation}

Cerchiamo la soluzione simmetrica introducendo una perturbazione $x$ rispetto al valore medio:
\begin{equation}
    \theta_1 = \frac{\alpha}{2} + x \quad \text{e} \quad \theta_2 = \frac{\alpha}{2} - x 
\end{equation}
Sostituendo nell'uguaglianza dei coseni e sviluppando con le formule di addizione:
\begin{equation}
   \cos \theta_1 \cos\left( \frac{\alpha}{2} - x \right) = \cos \theta_2 \cos\left( \frac{\alpha}{2} + x \right)
\end{equation}
\begin{equation}
 \cos\left(\frac{\alpha}{2}\right) \cos(x) ( \cos \theta_1 - \cos \theta_2 ) + \sin\left(\frac{\alpha}{2}\right) \sin(x) ( \cos \theta_1 + \cos \theta_2 ) = 0
\end{equation}
Poiché $\cos(\alpha/2)$ e $\sin(\alpha/2)$ sono ortogonali (lin. indipendenti), l'equazione è soddisfatta solo se si annullano contemporaneamente entrambi i coefficienti:
\begin{equation}
    \cos(x) (\cos \theta_1 - \cos \theta_2)= 0 \qquad \text{e} \qquad \sin(x) (\cos \theta_1 + \cos \theta_2)= 0
\end{equation}
Le soluzioni che includono angoli $>\pi/2$ non hanno significato fisico per il nostro prisma. L'unica soluzione accettabile si ha per $x=0$, che implica la simmetria perfetta del raggio luminoso all'interno del prisma:
\begin{equation}
    \begin{cases}
        \theta_1 = \theta_2 \equiv \theta\\
        \theta_1' = \theta_2' \equiv \theta' = \frac{\alpha}{2}
    \end{cases}
\end{equation}
Sostituendo questa condizione nell'Equazione \ref{eq:deviazione}, l'angolo di deviazione diventa $\delta_{\text{min}} = 2\theta - \alpha$, da cui $\theta = \frac{\delta_{\text{min}} + \alpha}{2}$. Infine, applicando la legge di Snell all'interfaccia ($\sin \theta = n \sin \theta'$, in cui si è tenuto conto che $n_{aria} \sim 1$), ricaviamo la formula fondamentale dell'esperienza:
\begin{definizione}[title=Indice di rifrazione tramite deviazione minima]
Misurando l'angolo al vertice $\alpha$ e l'angolo di deviazione minima $\delta_{\text{min}}$, l'indice di rifrazione del prisma è dato da:
\begin{equation}
    n = \frac{\sin\left(\frac{\delta_{\text{min}} + \alpha}{2}\right)}{\sin\left(\frac{\alpha}{2}\right)}
\end{equation}    
\end{definizione}

\begin{enumerate}
    \item Si legge il valore sulla scala principale superato dallo zero del nonio (es. $175.5^\circ$).

    \item La misura finale sarà $175.5^\circ + \frac{5}{60}^\circ$.
\end{enumerate}

\subsection{Procedura di misurazione}
La procedura si divide in due fasi principali:
\begin{enumerate}
    \item \textbf{Misura dello zero ($\theta_0$):} Senza il prisma, si allinea il cannocchiale direttamente davanti al collimatore. Si centra l'immagine della fenditura sul mirino e si legge l'angolo $\theta_0$. Questa misura è necessaria perché lo "zero" ottico non coincide necessariamente con lo "zero" della scala graduata. La misura di $\theta_0$ va ripetuta a ogni cambio di lunghezza d'onda/filtro per sicurezza.
    \item \textbf{Ricerca del minimo per la lampada a Sodio:} Si inserisce il prisma. Osservando (tramite un foglio di carta) si cerca il raggio rifratto deviato. Ruotando il piatto che sostiene il prisma, il raggio si sposterà, fino a raggiungere un punto di "inversione" (il raggio si ferma e torna indietro pur continuando a ruotare il prisma nello stesso verso). Quello è il punto di deviazione minima. Si inquadra la fenditura col cannocchiale, si affina la posizione muovendo il piatto e si legge l'angolo $\theta_1$.
    \item \textbf{Misure con luce bianca e filtri:} Per le altre lunghezze d'onda, l'intensità luminosa dietro ai filtri (specie quelli agli estremi dello spettro, violetto e rosso profondo) è molto bassa. Conviene usare la luce bianca \textit{senza} filtro, inquadrare lo spettro continuo, posizionarsi approssimativamente sul colore desiderato trovando il suo punto di inversione, e solo a quel punto inserire il filtro interferenziale per fare la lettura accurata di $\theta_1$.
\end{enumerate}

Per ogni lunghezza d'onda, l'angolo di deviazione minima calcolato sarà $\delta_{\text{min}} = |\theta_1 - \theta_0|$.
Per ridurre le incertezze statistiche e gli errori di posizionamento, è fondamentale ripetere l'intera procedura (ricerca del minimo) \textbf{3 volte per ogni filtro}. Se le misurazioni sono eseguite correttamente, i tre valori di $\theta_1$ devono risultare compatibili entro l'errore di lettura del nonio. In caso contrario, si assume come valore la media e come errore la semidispersione massima $\frac{\theta_{\text{max}} - \theta_{\text{min}}}{2}$.

\textbf{Errori associati:}\\
Considerando l'incertezza di lettura del nonio, l'errore associato al singolo angolo letto è $\sigma_{\theta} = \frac{1^\circ/60}{\sqrt{3}}$.
L'errore propagato su $\delta_{\text{min}}$ sarà la somma in quadratura degli errori di $\theta_1$ e $\theta_0$:
\begin{equation}
    \sigma_{\delta} = \sqrt{\sigma_{\theta_1}^2 + \sigma_{\theta_0}^2} = \sqrt{2}\sigma_{\theta}
\end{equation}
\textit{(Nota: Prima di inserire gli angoli nelle formule per calcolare $n$, è necessario convertirli in radianti).}

Per confermare il modello teorico, effettueremo un fit dei dati secondo due modelli:
\begin{itemize}
    \item \textbf{Fit 1:} Riscriviamo l'equazione teorica, introducendo i parametri di fit $A$ e $B$ (dove $B$ sostituisce la lunghezza d'onda di risonanza $\lambda_0$):
    \begin{equation}
        y = \sqrt{1 + \frac{A x^2}{x^2 - B^2}}
    \end{equation}
    Il parametro $B$ è elevato al quadrato per mantenere la coerenza dimensionale al denominatore. 
    I valori da porre nei fit saranno: $A \simeq 1$ (dove in realtà A non è noto) e $B \simeq 100 \text{ nm}$. Il valore di $B$ significa che $\lambda_0 \simeq 100 \text{ nm}$, la risonanza è in una regione ultravioletta. È proprio per questo motivo che il vetro ci appare trasparente nello spettro del visibile (assenza di assorbimento, lontano dalla risonanza).
    
    \item \textbf{Fit Lineare:}
    \begin{equation}
        y = A + Bx
    \end{equation}
    Da questo fit ci aspettiamo un'intercetta all'origine $A \simeq 1.5$, che solleva la retta in corrispondenza del valore medio dell'indice di rifrazione del vetro, e un coefficiente angolare $B \sim 0$ (un valore molto vicino a zero). 
\end{itemize}

\begin{nota}[title=Confronto tra i modelli]
Confrontando il $\chi^2$ dei due fit, noteremo che il $\chi^2$ del modello di Sellmeier è minore di quello del fit lineare, indicando che i dati sperimentali "preferiscono" il modello fisico corretto. Tuttavia, la differenza potrebbe non essere evidente: nell'intervallo (piccolo) del visibile ($450-700 \text{ nm}$), la curvatura imposta dall'equazione di Sellmeier è modesta, e i punti si adattano visivamente a una semplice retta decrescente.
\end{nota}



\section{L'Arcobaleno} 

L'arcobaleno è un'applicazione del fenomeno della dispersione, dovuta alla dipendenza dell'indice di rifrazione dalla lunghezza d'onda della luce. 
Osservando un arcobaleno con il sole alle nostre spalle, possiamo notare le seguenti caratteristiche:
\begin{itemize}
    \item \textbf{Arco primario:} si forma ad un angolo $\theta \sim 40^\circ$ rispetto alla direzione dei raggi solari. Presenta il colore violetto nella parte bassa e il rosso nella parte alta.
    \item \textbf{Arco secondario:} visibile solo in condizioni ottimali, si trova ad un angolo maggiore e presenta i colori invertiti (rosso all'interno, violetto all'esterno).
    \item \textbf{Cielo in mezzo:} la porzione di cielo compresa tra i due archi risulta meno luminosa rispetto al cielo circostante.
\end{itemize}

\subsection*{Geometria del raggio nella goccia d'acqua}
Consideriamo una goccia d'acqua sferica di raggio $R$. Un raggio di luce incide su di essa caratterizzato da un \textit{parametro d'impatto} $b$ (ovvero la distanza della retta di incidenza dal centro della goccia). Sulla superficie di separazione, localmente piana, definiamo:
\begin{itemize}
    \item $i$ (o $\theta_i$): l'angolo di incidenza rispetto alla normale (il raggio passante per il centro).
    \item $r$ (o $\theta_r$): l'angolo di rifrazione.
\end{itemize}
Quando la luce colpisce la goccia, subisce diverse interazioni, suddivisibili in "classi" di raggi:
\begin{enumerate}
    \item \textbf{Raggio di prima classe:} la parte di luce che viene immediatamente riflessa all'esterno (non contribuisce all'arcobaleno).
    \item \textbf{Raggio di seconda classe:} il raggio che subisce una rifrazione, attraversa la goccia ed esce senza subire riflessioni interne.
    \item \textbf{Raggio di terza classe:} il raggio che subisce una rifrazione, \textit{una riflessione interna} ed esce dalla goccia verso l'osservatore. \textbf{Questo genera l'arcobaleno primario.}
    \item \textbf{Raggio di quarta classe:} il raggio che subisce una rifrazione, \textit{due riflessioni interne} ed esce. \textbf{Questo genera l'arcobaleno secondario.}
\end{enumerate}

Tracciando geometricamente il percorso del raggio di terza classe all'interno della goccia e prolungando i raggi incidente e uscente, si individua un angolo esterno $\Delta$, detto \textbf{angolo di deviazione totale}.

L'angolo $\Delta$ si calcola come somma delle singole deviazioni subite dal raggio alle varie interfacce:
\[
\Delta = (i - r) + (\pi - 2r) + (i - r) = \pi + 2i - 4r
\]
Utilizzando la legge di Snell per l'interfaccia aria-acqua e approssimando $n_{\text{aria}} \simeq 1$, si ha:
\begin{equation}
    \frac{\sin i}{\sin r} = n \implies r = \arcsin\left(\frac{\sin i}{n}\right)
\end{equation}
Sostituendo $r$, l'angolo di deviazione diventa una funzione dipendente solo dall'angolo di incidenza $i$:
\begin{equation}
   \Delta(i)  = \pi + 2i - 4\arcsin\left(\frac{\sin i}{n}\right)
\end{equation}

\subsection*{Calcolo dell'angolo per l'arcobaleno primario}
Per trovare la direzione in cui la luce è più intensa, dobbiamo cercare i punti di stazionarietà (minimo) della deviazione $\Delta(i)$. Deriviamo rispetto ad $i$ e poniamo uguale a zero:
\begin{equation}
    \frac{d \Delta}{d i} = 2 - \frac{4}{\sqrt{1 - \frac{\sin^2 i}{n^2}}} \cdot \frac{\cos i}{n} = 0
\end{equation}
Risolviamo per trovare l'angolo $i$:
\begin{equation}
    2\sqrt{1 - \frac{\sin^2 i}{n^2}} = 4 \frac{\cos i}{n} \implies n^2 - \sin^2 i = 4 \cos^2 i
\end{equation}
Ricordando che $\cos^2 i = 1 - \sin^2 i$, otteniamo:
\begin{equation}
     \sin^2 i = \frac{4 - n^2}{3}
\end{equation}
Utilizzando l'indice di rifrazione dell'acqua ($n_{\text{acqua}} \simeq 1.33$), calcoliamo i valori numerici:
\[
    i \simeq 0.86 \text{ rad} \implies i \simeq 59^\circ \quad \text{ed} \quad r \simeq 40^\circ
\]
Inserendo questi valori, la deviazione minima è:
\begin{equation}
    \Delta_{\text{min}} \simeq 138^\circ
\end{equation}
Poiché $\sin i = \frac{b}{R}$, troviamo che questo avviene per un parametro di impatto $b \simeq 0.86 R$.
L'angolo di osservazione dell'arcobaleno primario rispetto ai raggi incidenti è il supplementare della deviazione minima: $180^\circ - 138^\circ = 42^\circ$.

\begin{nota}
Poiché l'indice di rifrazione $n$ dipende dalla lunghezza d'onda (dispersione), l'angolo di uscita varia leggermente per ogni colore. Questo "apre" la luce bianca solare nello spettro visibile dell'arcobaleno.
\end{nota}

\section{Esperienza 4: Polarizzazione della luce}

Ricordando che le onde elettromagnetiche sono onde trasversali: il campo elettrico $\vec{E}$ e il campo magnetico $\vec{B}$ oscillano su un piano ortogonale alla direzione di propagazione. Possiamo prendere come riferimento il campo elettrico e descriverlo come un vettore bidimensionale nel piano trasverso alla direzione di propagazione (asse $z$). Scegliamo come base gli assi $x$ e $y$.

\subsection*{Tipi di Polarizzazione}
Il caso più semplice è la \textbf{polarizzazione lineare}, in cui il campo oscilla lungo una singola direzione fissa:
\[
\vec{E} = E_0 (\cos \theta \hat{x} + \sin \theta \hat{y})
\]
In questo caso, le componenti $E_x$ ed $E_y$ oscillano perfettamente in fase tra loro.

In generale, le due componenti del campo possono avere uno sfasamento $\phi$:
\begin{align*}
    E_x &= E_{x0} \cos(\omega t) \\
    E_y &= E_{y0} \cos(\omega t + \phi)
\end{align*}
Il punto descritto dalla punta del vettore $\vec{E}$ si muoverà nel piano tracciando una curva. Riscriviamo le equazioni:
\[
\frac{E_x}{E_{x0}} = \cos(\omega t) \hspace{2cm} \frac{E_y}{E_{y0}} = \cos(\omega t)\cos\phi - \sin(\omega t)\sin\phi
\]
Combinando queste due equazioni ed eliminando il tempo $t$, si ottiene l'equazione generale di un'ellisse:
\begin{equation}
    \left(\frac{E_x}{E_{x0}}\right)^2 + \left(\frac{E_y}{E_{y0}}\right)^2 - 2 \frac{E_x}{E_{x0}} \frac{E_y}{E_{y0}} \cos\phi = \sin^2 \phi
\end{equation}
L'asse maggiore dell'ellisse risulta inclinato rispetto all'asse $x$ di un angolo $\beta$ tale che:
\[
\tan(2\beta) = \frac{2 E_{x0} E_{y0} \cos\phi}{E_{x0}^2 - E_{y0}^2}
\]
Questa situazione descrive la \textbf{polarizzazione ellittica}. Esistono due casi notevoli:
\begin{itemize}
    \item \textbf{Polarizzazione Lineare:} Se $\phi = 0$ o $\phi = \pi$, l'ellisse degenera in un segmento. Le due componenti sono in fase o in controfase.
    \item \textbf{Polarizzazione Circolare:} Se $\phi = \frac{\pi}{2}$ o $\frac{3\pi}{2}$ e le ampiezze sono uguali ($E_{x0} = E_{y0}$), la curva diventa una circonferenza. A seconda del segno della fase, il vettore ruoterà in senso orario (circolare destra) o antiorario (circolare sinistra).
\end{itemize}

\subsection*{Polarizzatori e Legge di Malus}
Come si può polarizzare una luce non polarizzata? Si utilizzano i \textbf{polarizzatori}, tipicamente lastre di materiale polimerico. Le lunghe molecole dei polimeri sono allineate in una specifica direzione.
\begin{itemize}
    \item Se il campo elettrico oscilla \textbf{parallelamente} alle catene polimeriche, compie lavoro sugli elettroni del materiale e viene \textbf{assorbito}.

\end{itemize}

Per le ampiezze dei campi vale la relazione $E_2 = E_1 \cos \alpha$. 
Poiché l'intensità luminosa è proporzionale al quadrato dell'ampiezza del campo elettrico ($I \propto E^2$), si ricava la:

\begin{definizione}[title=Legge di Malus]
    L'intensità $I_2$ della luce trasmessa dal secondo polarizzatore è data da:
    \begin{equation}
        I_2 = I_1 \cos^2 \alpha
    \end{equation}
    dove $I_1$ è l'intensità della luce incidente sull'analizzatore e $\alpha$ è l'angolo tra gli assi di trasmissione dei due polarizzatori.
\end{definizione}

\textbf{Cosa accade invece al primo polarizzatore?} \\
La luce emessa da una normale lampadina a filamento è generata dalla diseccitazione di atomi indipendenti, emettendo onde con direzioni di polarizzazione e fasi del tutto casuali (luce non polarizzata). 
Applicando la Legge di Malus a questa luce, l'angolo $\alpha$ assunto dalle varie onde è aleatorio. Occorre quindi calcolare il valore medio della funzione $\cos^2 \alpha$ su tutti gli angoli possibili tra $0$ e $2\pi$, che risulta essere esattamente $\frac{1}{2}$. 
Pertanto, l'intensità della luce uscente dal primo polarizzatore sarà esattamente la metà dell'intensità iniziale:
\begin{equation}
    I_1 = \frac{1}{2}I_0
\end{equation}



\subsubsection{Notazione: Il Vettore di Jones}
Per descrivere lo stato di polarizzazione della luce in modo compatto si utilizza il formalismo dei \textbf{vettori di Jones}. 
Dato un campo elettrico $\vec{E} = E_x \hat{i} + E_y \hat{j}$, le cui componenti nel piano trasverso sono:
\[
E_x = E_{x0} \exp(i\Phi_x) \hspace{1cm} E_y = E_{y0} \exp(i\Phi_y)
\]
possiamo rappresentarlo in notazione vettoriale come:
\[
\begin{pmatrix}
E_x \\
E_y
\end{pmatrix}
=
\begin{pmatrix}
E_{x0}\exp(i\Phi_x) \\
E_{y0}\exp(i\Phi_y)
\end{pmatrix}
\]
Questa notazione matriciale, normalizzando le ampiezze, ci permette di scrivere gli stati di polarizzazione fondamentali in modo molto semplice:
\begin{itemize}
    \item $\begin{pmatrix} 1 \\ 0 \end{pmatrix}$: Polarizzazione lineare lungo l'asse $x$.
    \item $\begin{pmatrix} 0 \\ 1 \end{pmatrix}$: Polarizzazione lineare lungo l'asse $y$.
    \item $\begin{pmatrix} 1 \\ 1 \end{pmatrix}$: Polarizzazione lineare inclinata a $\frac{\pi}{4}$ (45°) rispetto a $x$.
    \item $\begin{pmatrix} 1 \\ i \end{pmatrix}$: Polarizzazione circolare \textbf{sinistra}.
    \item $\begin{pmatrix} 1 \\ -i \end{pmatrix}$: Polarizzazione circolare \textbf{destra}.
\end{itemize}

Questo formalismo risulta estremamente utile per le combinazioni di stati. Ad esempio, se sommiamo una polarizzazione circolare destra e una sinistra:
\begin{equation}
    \begin{pmatrix} 1 \\ i \end{pmatrix} + \begin{pmatrix} 1 \\ -i \end{pmatrix} = \begin{pmatrix} 2 \\ 0 \end{pmatrix} \propto \begin{pmatrix} 1 \\ 0 \end{pmatrix}
\end{equation}
Si nota immediatamente che il risultato è una polarizzazione lineare. Questo significa che, esattamente come possiamo scomporre un vettore lineare nelle sue componenti $x$ e $y$, possiamo anche descriverlo come la sovrapposizione di due onde polarizzate circolarmente (destra e sinistra). È puramente una scelta della base vettoriale.

\subsection{Verifica della legge di Malus}

\subsubsection*{Apparato Sperimentale}
L'apparato per verificare la legge di Malus è montato su un binario ottico ed è composto da:
\begin{itemize}
    \item Una \textbf{sorgente} di luce bianca.
    \item Il \textbf{primo polarizzatore}, posizionato a distanza intermedia (né troppo vicino né troppo lontano dalla sorgente).
    \item Il \textbf{secondo polarizzatore} (analizzatore), messo il più vicino possibile al primo per garantire che tutta la luce trasmessa dal primo attraversi anche il secondo.
    \item Un \textbf{fotodiodo} (acceso e collegato a un voltmetro) accuratamente mascherato per evitare la saturazione. 
\end{itemize}

\subsubsection*{Funzione di Fit e Parametri}
I dati acquisiti in laboratorio descriveranno una curva che interpoleremo (in radianti) con la funzione:
\begin{equation}
    y = A \cos^2(x - C) + B
\end{equation}
Analizziamo il significato fisico dei tre parametri di fit:
\begin{itemize}
    \item $\mathbf{A}$: Rappresenta l'intensità massima trasmessa ($I_{\text{max}}$).
    \item $\mathbf{C}$: È un angolo di fase (correzione dello zero). L'angolo "zero" letto sulla scala graduata potrebbe non coincidere con il perfetto allineamento degli assi dei due polarizzatori. Il parametro $C$ trasla la funzione per compensare questo disallineamento e dipenderà fortemente da come viene inizializzato il fit.
    \item $\mathbf{B}$: Rappresenta il termine di fondo, ovvero la luce residua misurata nei punti di minimo della curva.
\end{itemize}

    \draw[very thick, red!70!black]  (0,0) -- (Q2);
    \node[inner sep=0pt,
          pin={[pin distance=1.4cm, pin edge={thin, gray}]140:{$\sqrt{\varepsilon}\,E_1\sin\alpha$}}]
          at (Q2) {};

    \node at (0,-1.7) {(b) proiezione sull'asse di $P_2$};
  \end{scope}

\end{tikzpicture}
\end{center}

Di conseguenza, la luce in uscita dal primo polarizzatore \textbf{non è perfettamente polarizzata linearmente}, ma possiede una polarizzazione \textbf{ellittica molto schiacciata}.
Avremo quindi una componente di ampiezza massima $E_1$ lungo l'asse principale di trasmissione, e una componente molto piccola (che chiameremo $\sqrt{\varepsilon} E_1$) lungo l'asse ortogonale. 

Quando questa luce ellittica incontra il secondo polarizzatore (ruotato di un angolo $\alpha$), l'intensità totale trasmessa $I_2$ sarà la somma dei contributi delle due componenti proiettate sull'asse dell'analizzatore:
\begin{equation}
    I_2 = I_1 \cos^2 \alpha + (\varepsilon I_1) \sin^2 \alpha
\end{equation}
Ricordando l'identità trigonometrica $\sin^2 \alpha = 1 - \cos^2 \alpha$, possiamo riscrivere:
\begin{equation}
    I_2 = I_1 \cos^2 \alpha + \varepsilon I_1 (1 - \cos^2 \alpha)
\end{equation}
Raggruppando i termini in $\cos^2\alpha$, otteniamo:
\begin{equation}
    I_2 = I_1(1 - \varepsilon)\cos^2 \alpha + \varepsilon I_1
\end{equation}
\begin{nota}
Come si vede dall'equazione, emerge un termine costante $B = \varepsilon I_1$. Questo dimostra che il "sollevamento" dei minimi della legge di Malus è dovuto principalmente all'ellitticità della luce prodotta dal polarizzatore. Per questo motivo, l'effetto della luce ambientale diventa trascurabile rispetto a questa problematica strumentale.
\end{nota}

\subsubsection*{Analisi degli errori e sistematiche}
Le incertezze sulla nostra misurazione proverranno da diverse fonti:
\begin{itemize}
    \item \textbf{Errore di lettura (scala graduata):} L'allineamento manuale tacca su tacca (sensibilità di $1^\circ$).
    \item \textbf{Errore del multimetro:} L'incertezza sulla lettura della tensione del fotodiodo.
    \item \textbf{Disuniformità del polarizzatore:} È la fonte di errore sistematico maggiore. L'asse di rotazione del polarizzatore potrebbe non coincidere perfettamente col centro del fascio di luce. Ruotando, il fascio di luce colpirà porzioni diverse del polimero. A causa di difetti di fabbrica, disuniformità costruttive o semplice polvere, il grado di assorbimento varierà leggermente in base al punto colpito.
\end{itemize}

Questo ultimo effetto sarà visibile tracciando il grafico dei \textbf{residui} (3° grafico). Osserveremo un andamento oscillante.
Prendendo l'ampiezza di questa oscillazione ($\Delta V$) e dividendola per l'ampiezza massima del segnale ($V_{\text{max}}$), il rapporto $\frac{\Delta V}{V_{\text{max}}}$ ci fornirà una stima quantitativa della disuniformità superficiale del polarizzatore.

Infine, si potrà notare che l'inizio e la fine della curva (a $0^\circ$ e a $360^\circ$) potrebbero non combaciare perfettamente (la curva "non si chiude"). Ciò è dovuto a piccole variazioni della risposta dello strumento nel corso del tempo: durante il tempo necessario a prendere le misure, il riscaldamento della lampadina e la reazione del fotodiodo possono causare una lenta variazione dell'intensità o della sensibilità di fondo.
